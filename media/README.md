# 미디어 교체 안내

현재 `sample-audio.mp3`와 `sample-video.mp4`는 태그 동작 확인용으로 생성한 무음 샘플입니다. SVG 3개도 제출 구조를 확인하기 위한 자체 제작 placeholder입니다.

제출 전 다음처럼 교체하세요.

1. 본인 또는 사용 허가된 이미지 3개를 이 폴더에 넣습니다.
2. `html/myTrip.html`과 `html/index.html`의 경로와 `alt`를 수정합니다.
3. 본인 또는 사용 허가된 오디오·영상을 넣고 `<source>` 경로와 MIME type을 수정합니다.
4. 불필요한 샘플 파일을 제거합니다.
