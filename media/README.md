# 미디어 파일 기록

현재 페이지에서 실제로 사용하는 파일과 정리 방법을 기록했습니다.

| 파일 | 사용 위치 | 출처·처리 내용 |
|---|---|---|
| `main_image.jpeg` | 메인 화면 | 개인 여행 기록 사진 |
| `img_1.jpg` | 산티아고 여행 카드 | 개인 여행 기록 사진 |
| `img_2.jpg` | 뉴욕 여행 카드 | 개인 여행 기록 사진 |
| `img_3.jpg` | 홍콩 여행 카드 | 개인 여행 기록 사진 |
| `video_1_720p.mp4` | 여행 영상 | 개인 촬영 영상을 720p H.264/AAC MP4로 정리 |
| `travel-ambient.mp3` | 여행 오디오 | FFmpeg의 pink noise에 high-pass, low-pass, fade 필터를 적용해 로컬에서 직접 생성 |
| `favicon.svg` | 모든 페이지 | 이 과제에서 사용하는 단순 SVG 아이콘 |

오디오는 외부 음악이나 다운로드한 음원을 사용하지 않았습니다. 영상은 세로 원본 비율을 유지해 표시하며, HTML의 MIME type과 실제 MP4 컨테이너가 일치하도록 정리했습니다.
